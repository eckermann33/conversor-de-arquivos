# Arquivos de exemplo

Arquivos pequenos para testar o CONVRT sem precisar caçar algo no seu computador.

| Arquivo | Serve para testar |
| --- | --- |
| `exemplo.csv` | CSV → JSON / XLSX / MD (tem vírgula em campo, aspas escapadas e quebra de linha) |
| `exemplo.json` | JSON → CSV / YAML / XML / SQL / XLSX (tem objeto aninhado e array) |
| `exemplo.md` | MD → HTML / PDF / DOCX |
| `exemplo.txt` | TXT → PDF / DOCX, caixa do texto, relatório |
| `exemplo.xml` | XML → JSON (com atributos) |
| `exemplo.yaml` | YAML → JSON |
| `exemplo.srt` | SRT → VTT |
